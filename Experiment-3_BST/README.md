# Experiment 03 - Binary Search Tree

## Aim

To implement Binary Search Tree (BST) and perform Preorder, Inorder, and Postorder traversals using C.

## Language

C

## Traversals

- Preorder (Root → Left → Right)
- Inorder (Left → Root → Right)
- Postorder (Left → Right → Root)

## Time Complexity

- Insertion: O(log n) (Average), O(n) (Worst Case)
- Preorder: O(n)
- Inorder: O(n)
- Postorder: O(n)

## Space Complexity

O(n)
